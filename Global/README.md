# 🌍 Global Happiness Analysis

### A Python-based data analysis project to explore happiness scores across countries, regions, and years.

---

## 📌 Project Overview

This project analyzes the **Global Happiness Dataset** using Python.  
It helps us understand which countries and regions have higher happiness scores and which factors are related to happiness.

The project includes data cleaning, exploratory data analysis, visualizations, correlation analysis, and result interpretation.

---

## 📊 Dataset

The dataset contains happiness-related information for different countries and years.

### Dataset Columns

| Column Name | Description |
|---|---|
| Ranking | Country ranking based on happiness score |
| Country | Name of the country |
| Regional indicator | Region of the country |
| Happiness score | Overall happiness score |
| GDP per capita | Economic output per person |
| Social support | Support available from family, friends, and society |
| Healthy life expectancy | Expected healthy years of life |
| Freedom to make life choices | Freedom to make personal life choices |
| Generosity | Generosity level in the country |
| Perceptions of corruption | Perceived level of corruption |
| Year | Year of the record |

## 🔍 Key Insights

- GDP per capita, social support, and healthy life expectancy show a positive relationship with happiness score.
- Countries with stronger social support generally have higher happiness scores.
- Happiness levels differ across regional indicators.
- Correlation shows relationships between variables, not direct cause-and-effect.
